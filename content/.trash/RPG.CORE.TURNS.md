# RPG.CORE.TURN

#rpg #turns #combat

🧭 ID: RPG.CORE.TURN

⚙️ DESCRIÇÃO

Define o sistema de turnos, ordem de ação, reação, simultaneidade, interrupções e resolução de combate.

---

# ⚔️ ESTRUTURA BÁSICA DO TURNO

📌 PRINCÍPIO CENTRAL

O combate é estruturado em ciclos de:

- Ação
- Reação
- Resolução

---

# 🔄 ORDEM DE COMBATE

📌 INÍCIO DO COMBATE

A ordem é definida no início da luta através de:

- D6 + DEX

📊 RESULTADO

Maior resultado age primeiro.

Essa ordem se mantém até o fim do combate, salvo efeitos que alterem iniciativa.

---

# ⚔️ CICLO DE TURNO

📌 FLUXO PADRÃO

1. Jogador A executa AÇÃO
2. Jogador B executa REAÇÃO
3. Resolve-se o resultado
4. Inverte-se a ordem no próximo ciclo

---

# 🎯 AÇÃO

📌 DEFINIÇÃO

Ação é qualquer ação que altera o estado da batalha.

📌 EXEMPLOS

- Ataque
- Defesa ativa
- Uso de técnica
- Movimento estratégico
- Invocação
- Cura
- Reforço ativo

📌 REGRAS

- Cada jogador possui 1 ação por turno
- Ação define o que será resolvido no ciclo

---

# ⚡ REAÇÃO

📌 DEFINIÇÃO

Reação é a resposta direta à ação do oponente.

📌 TIPOS

- Defesa
- Esquiva
- Contra-ataque
- Interferência situacional

📌 REGRAS

- Toda ação gera uma reação obrigatória
- Reação não consome turno separado
- Reação resolve dentro do mesmo ciclo

---

# 🧠 INTERRUPÇÃO

📌 REGRA

Não existe “interrupção livre” fora do sistema.

📌 EXCEÇÃO

Interferência só ocorre se:

- Corpo a corpo
OU
- SUPER DEX ativado
OU
- Técnica permitir explicitamente

📌 CONSEQUÊNCIA

Se permitido:

- a ação é contestada imediatamente via reação

---

# ⚔️ SIMULTANEIDADE

📌 REGRA

Ações podem ser simultâneas apenas se:

- Ambos atacam no mesmo alvo
OU
- Diferença de sincronia for ≤ 3 (D6)

📊 RESULTADO

- Se diferença > 3 → resolve por ordem normal
- Se diferença ≤ 3 → ações simultâneas

📌 CONSEQUÊNCIA

- Ambos podem acertar
- Ambos podem errar
- Ambos podem trocar dano

---

# 🌀 CONTRA-ATAQUE (SUPER DEX)

📌 REGRA

Usuário com SUPER DEX pode:

- Executar reação
- E imediatamente transformar em ação

📌 EFEITO

- Cancela ou substitui a ação inimiga, se superior na resolução

---

# 🔁 RESOLUÇÃO

📌 ORDEM

Após ação + reação:

1. Rolagens são feitas
2. Resultado é calculado
3. Efeitos são aplicados imediatamente

📌 REGRA

O estado da batalha muda APENAS após resolução completa.

---

# 🔋 AÇÕES LIVRES

📌 DEFINIÇÃO

Ações que NÃO alteram estado da batalha.

📌 EXEMPLOS

- Falar
- Olhar ao redor
- Empunhar arma
- Ajustar postura leve

📌 REGRA

- Não consomem turno
- Não geram reação obrigatória
- Podem ser interrompidas por ação ofensiva válida

---

# 🧘 RECUPERAÇÃO

📌 REGRA

Existe janela de recuperação dentro do turno.

📌 FUNCIONAMENTO

- Pode recuperar energia
- A cada 2 ciclos pode recuperar postura
- Não consome ação principal se declarado como recuperação

📌 LIMITAÇÃO

- Durante recuperação, não pode executar ação ofensiva simultânea

---

# ⚡ AÇÕES NULA / PREPARAÇÃO

📌 DEFINIÇÃO

Turno sem ação efetiva.

📌 FUNÇÃO

- Recuperação
- Preparação
- Foco
- Regeneração

📌 REGRA

- Ainda gera reação se interrompido
- Mas não altera estado diretamente

---

# 🧠 CONTROLE DE INTERFERÊNCIA

📌 REGRA CENTRAL

Se um jogador declara ação:

- Ele está comprometido com aquela ação

📌 CONSEQUÊNCIA

O oponente só pode:

- reagir
OU
- tentar interferir via regra válida

Nunca existe “cancelamento livre” fora do sistema.

---

# ⚠️ CANCELAMENTO DE AÇÃO

📌 REGRA

Uma ação só é cancelada se:

- Falha de rolagem
OU
- Interferência válida superior
OU
- Contra-ataque com SUPER DEX bem-sucedido

---

# 📊 DISTÂNCIA E INTERAÇÃO

📌 REGRA

- Corpo a corpo → permite interferência direta
- Longa distância → exige reação ativa ou técnica

---

# 🧩 SINCRONIA

📌 REGRA

Certos eventos podem gerar sincronização de ações:

- Ambos atacam ao mesmo tempo
- Ambos reagem simultaneamente

📌 MECÂNICA

- D6 define diferença de sincronia
- ≤ 3 → simultâneo
- > 3 → ordem normal

---

# 📌 REGRA CENTRAL

- Ação define intenção
- Reação define resposta
- Resolução define realidade
- Nada muda o estado antes da resolução
- SUPER DEX permite quebra de fluxo
- Simultaneidade só ocorre sob condição mecânica
