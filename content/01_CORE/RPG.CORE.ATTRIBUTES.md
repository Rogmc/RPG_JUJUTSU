# RPG.CORE.ATTRIBUTES

#rpg #core

🧭 ID: RPG.CORE.ATTRIBUTES

⚙️ DESCRIÇÃO

Define os atributos base, proficiências e regras de criação e progressão de personagem.

🧱 ATRIBUTOS BASE

Representam a capacidade fundamental do personagem.

DEX (Destreza)  
INT (Intelecto)  
FOR (Força)

📏 ESCALA

Mínimo: 1  
Padrão: até 8  
Despertar: até 12  

📐 USO DOS ATRIBUTOS

Ataque físico → FOR  
Ataque com arma → DEX  
Esquiva → DEX  
Técnica → INT  
Percepção → INT  
Velocidade → DEX  

🎯 PROFICIÊNCIAS

Representam domínio prático.

FÍSICO  
[[RPG.CORE.PROFICIENCIES|CONTROLE]]  
COMBATE  
RESISTÊNCIA  
[[RPG.TECHNIQUE.SYSTEM|TÉCNICA]]  
(opcionais: INVOCADOR, PERCEPÇÃO)

📊 ESCALA DE PROFICIÊNCIA

Padrão: até 6  
Despertar: até 12  

⚖️ FUNÇÃO DAS PROFICIÊNCIAS

Definem vantagem em testes opostos  
Podem gerar bônus residual  
Afetam qualidade, dano e efeitos  

📌 USO

1 principal por ação  
Pode usar 1 secundária apenas com SUPER ATRIBUTO  

🧬 CRIAÇÃO DE PERSONAGEM

📌 PASSO 1 — EXPERIÊNCIA

Rolar 1d6:

1 → não pertence à escola  
2–3 → primeiro ano  
4–5 → segundo ano  
6 → terceiro ano  

📌 PASSO 2 — LIMITES DE ATRIBUTO

1 → máximo 3 (sem mínimo)  
2–3 → máximo 4  
4–5 → máximo 5  
6 → máximo 6 (mínimo 2)  

📌 PASSO 3 — DISTRIBUIÇÃO

Jogador define os valores dentro dos limites  

📈 PROGRESSÃO

XP evolui atributos conforme nível  

📊 CUSTO

Nível 1–10 → custo 100  
Nível 11–15 → custo 200  
Nível 16+ → custo 350  

⚡ SUPER ATRIBUTO

Ativado a partir de valor 6  

SUPER = ATRIBUTO - 6  
MULT = floor(SUPER / 2)

📌 USO

Pode usar todos os MULT no turno  
Permite combinar proficiências  
Gera efeitos especiais (ações extras, múltiplos impactos, etc.)  

🛡️ POSTURA

[[RPG.CORE.RESOURCES|POSTURA]]  
Influenciada por FOR + DEX  

🧠 CONTROLE

[[RPG.ENERGY.CONTROL|CONTROLE]]  
Não substitui INT  
Define bônus, vantagem e eficiência de energia  

📌 REGRAS IMPORTANTES

Não existe atributo 0  
Atributo mínimo é 1  
Atributo define chance  
Proficiência define domínio  
Super atributo define expansão de ação  

🎯 ESPECIALIZAÇÃO

Permitida  

Ex:

COMBATE: KATANA  
TÉCNICA: SOMBRAS  

→ concede bônus situacional
